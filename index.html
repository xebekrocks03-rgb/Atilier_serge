Questions fréquentes

Comment je paie l’abonnement ?

Par mobile money, directement sur le numéro +228 91 29 43 45. Vous envoyez 5 000 FCFA, puis vous saisissez le code de la transaction dans l’application.

Quand mon accès est-il activé ?

Après la vérification de votre paiement. Une fois activé, appuyez sur « Actualiser mon accès » dans l’application.
